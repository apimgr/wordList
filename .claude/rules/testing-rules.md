# Testing, Documentation, and Accessibility Rules (PART 28, 29, 30)

⚠️ **These rules are NON-NEGOTIABLE. Violations are bugs.** ⚠️

## CRITICAL - NEVER DO

- Never treat manual binary validation as the automatic unit-test gate.
- Never leave translations, docs, route coverage, or accessibility requirements out of a feature change.

## CRITICAL - ALWAYS DO

- Maintain required unit, integration, container, and browser E2E coverage.
- Provide MkDocs/ReadTheDocs documentation and translation parity for supported locales.

## Key rules summary

Use temporary test data, verify actual behavior, and keep all docs synchronized. See AI.md PART 28, PART 29, and PART 30.
