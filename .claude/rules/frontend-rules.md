# Frontend Rules (PART 16)

⚠️ **These rules are NON-NEGOTIABLE. Violations are bugs.** ⚠️

## CRITICAL - NEVER DO

- Never require JavaScript for core functionality or use inline scripts/styles/handlers.
- Never omit a required public server page or expose credentials in page output.

## CRITICAL - ALWAYS DO

- Render pages server-side with accessible, responsive, theme-aware shared chrome.
- Keep forms functional without JavaScript and translate every user-facing string.

## Key rules summary

Use the shared page shell and components, safe HTML rendering, and required PWA and SEO support. See AI.md PART 16.
